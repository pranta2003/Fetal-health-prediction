# Fetal Core Python Package
Core reusable modular package containing dataset loaders, model architectures, loss functions, and evaluators.
Subpackages isolate clinical tabular models, multi-organ segmentation, landmark regression, and Hadlock fusion.
Zero data leakage: strict separation between antepartum maternal features and post-delivery outcome variables.
For a full file-by-file breakdown and workflow mapping, see [docs/FILE_GUIDE.md](../../docs/FILE_GUIDE.md).
