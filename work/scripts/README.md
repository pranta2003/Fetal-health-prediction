# Pipeline & Benchmark Scripts
Executable Python scripts for data preparation, model training, Kaggle kernel building, and evaluation.
Organized by anatomy and modality across HC18, AC, Femur, Head landmarks, FASSD, Tabular, and Fusion.
All scripts maintain deterministic seeds, patient-grouped splits, and strict cryptographic ledger audits.
For a full file-by-file breakdown and workflow mapping, see [docs/FILE_GUIDE.md](../docs/FILE_GUIDE.md).
